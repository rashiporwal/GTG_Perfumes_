## ✨ Features

- 📱 **Fully Responsive**: Optimized for mobile, tablet, and desktop.
- 🎨 **Modern UI/UX**: Clean design with gradients, badges, and interactive sections.
- 🖼️ **Product Gallery**: Main image, thumbnails, arrows, and dots for navigation.
- 🛒 **Subscription Options**: Single and double subscription cards with fragrance selection.
- 📊 **Comparison Table**: Sticky first column, scrollable on small screens.
- 📈 **Stats Section**: Animated counters and highlights.
- 📩 **Newsletter Form**: Styled input and button for user engagement.
- 🧭 **Responsive Navbar**: Hamburger menu for mobile, dropdowns for desktop.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic structure
- **CSS3** – Flexbox, Grid, Media Queries, Responsive Design
- **JavaScript (ES6)** – Interactive gallery, subscription logic
- **Custom Variables** – Colors, fonts, spacing for scalability
